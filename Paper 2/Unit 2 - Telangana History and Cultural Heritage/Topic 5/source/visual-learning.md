# Visual Learning

## Four-strand map
Adivasi resource resistance → Ramji Gond / Komaram Bheem
Agrarian struggle → Andhra Mahasabha / communists / village sanghams
Political crisis → MIM / Razakars / accession dispute
Integration → Operation Polo (13–17 Sep 1948) → continued armed struggle to 1951

## Key distinction
**17 September 1948 ended the Nizam’s military resistance; it did not end the Telangana peasant armed struggle.**

# Visual Learning and Answer Diagrams

## Monsoon mechanism — causal chain
```text
Seasonal solar heating + shifting tropical convergence
                    ↓
Land–ocean pressure/circulation contrast
                    ↓
Cross-equatorial flow + Somali low-level jet
                    ↓
Arabian Sea / Bay of Bengal moisture transport
                    ↓
Relief + monsoon trough + lows/depressions + intraseasonal oscillations
                    ↓
Spatially and temporally variable rainfall
```

## ENSO caution
```text
El Niño → often weaker large-scale monsoon circulation
        ↘ NOT deterministic ↙
IOD + intraseasonal variability + snow/land conditions + synoptic systems
```

## Flood-risk equation
```text
Disaster risk ≈ Hazard × Exposure × Vulnerability ÷ Coping capacity
```

## Basin-management loop
```text
Rainfall → runoff/recharge → river/aquifer storage → allocation/use
   ↑                                             ↓
land cover ← ecosystem condition ← return flows/pollution
```

## Energy transition logic
```text
Resource potential → generation capacity → grid evacuation → balancing/storage
→ reliable delivered electricity → affordability + environmental outcome
```

# Rebuild the topic

Edit any component `.md` file in this directory. Run `python build_topic.py` from an environment with Python, ReportLab, Mistune and Pillow installed. The script regenerates `complete-notes.md`, the printable PDF and offline HTML in the topic root. SVG diagrams are editable under `visuals/` and PNG renderings can be regenerated with CairoSVG. A rebuild resets the one-topic manifest and must be revalidated before distribution.

This is an expanded study draft, not academically approved.

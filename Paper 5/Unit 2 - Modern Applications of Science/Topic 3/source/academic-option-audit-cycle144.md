### Q2 — retain C ([A01])

- **A:** FALSE — chilling does not invariably increase bacteria; WHO says low temperature slows growth.
- **B:** FALSE — chilling does not remove dissolved salts; it is not desalination.
- **C:** SUPPORTED — refrigeration below 5°C slows but does not eliminate microbial growth; it is not sterilisation.
- **D:** FALSE — cold storage does not convert lactose to protein.

### Q3 — retain D ([A02])

- **A:** FALSE — sourness alone proves neither viable probiotic identity nor benefit.
- **B:** FALSE — an arbitrary living microbe is not automatically probiotic.
- **C:** FALSE — container material is not a criterion for probiotic status.
- **D:** SUPPORTED with scope — live microorganisms in adequate amounts must confer a host benefit; do not generalise clinical effects across products.

### Q4 — retain B ([A03])

- **A:** FALSE — Salmonella is a biological bacterial hazard.
- **B:** SUPPORTED — excessive pesticide residues are chemical hazards; mere detection is not necessarily a legal exceedance.
- **C:** FALSE — norovirus is a biological viral hazard.
- **D:** FALSE — pathogenic E. coli is a biological bacterial hazard.

### Q5 — retain B ([A04])

- **A:** FALSE — accurate declaration of intentionally added peanuts is labelling, not unintended transfer.
- **B:** SUPPORTED — FDA describes allergen transfer through inadequately cleaned shared equipment.
- **C:** FALSE — freezing a milk product does not demonstrate peanut cross-contact.
- **D:** FALSE — altered vitamin content is nutritional quality, not allergen cross-contact.

### Q6 — retain B ([A03])

- **A:** FALSE — HACCP is a preventive management system, not a laboratory assay.
- **B:** SUPPORTED — Codex requires hazard analysis, critical limits, monitoring, corrective actions and verification, rather than relying solely on end-product testing.
- **C:** FALSE — HACCP complements prerequisite good hygiene practices; it does not replace them.
- **D:** FALSE — a sampled final test cannot guarantee every unit of a batch is safe.

### Q7 — retain B ([A03])

- **A:** FALSE — carton colour is not a validated heat-treatment critical limit.
- **B:** SUPPORTED — a time-temperature deviation demands documented corrective action and affected-product disposition.
- **C:** FALSE — a customer-service number does not correct a thermal deviation.
- **D:** FALSE as stated — scheduled maintenance is not itself a failed CCP, although unsafe restart could become one.

### Q8 — retain A ([A05])

- **A:** SUPPORTED — the Food Safety and Standards Act, 2006 established FSSAI and the central statutory framework.
- **B:** FALSE — FSSAI identifies state food safety authorities as enforcement participants.
- **C:** FALSE — licensing and statutes cannot guarantee all future food batches.
- **D:** FALSE — the Act covers manufacture, storage, distribution, sale and import, not imports alone.

### Q19 — retain C ([A06])

- **A:** FALSE — clear water may still contain dissolved fluoride.
- **B:** FALSE — taste cannot establish arsenic absence.
- **C:** SUPPORTED — CDC warns that harmful germs and chemicals often do not change appearance, smell or taste.
- **D:** FALSE — turbidity cannot measure all microbiological and chemical hazards.

### Q20 — retain C ([A07][A08][A09])

- **A:** FALSE as an unsuitable option — activated alumina can reduce fluoride if correctly operated and monitored.
- **B:** FALSE as an unsuitable option — appropriate RO can reduce fluoride, with reject-water and maintenance requirements.
- **C:** SUPPORTED — ordinary chlorination disinfects; it does not remove dissolved fluoride ions.
- **D:** FALSE as an unsuitable option — a properly operated defluoridation process targets fluoride, but performance must be measured.

### Q26 — retain B ([A07][A09])

- **A:** FALSE as a universal claim — WHO notes that nitrite may oxidise to nitrate; that is not proof that chlorine always increases nitrate.
- **B:** SUPPORTED — disinfection is not dissolved-nitrate removal; source protection or contaminant-specific treatment is required.
- **C:** FALSE — nitrate is a chemical ion, not a virus.
- **D:** FALSE — chlorine is a recognised drinking-water disinfectant.

### Diagram-level scientific review — two blockers identified

**Diagram 01, food-safety HACCP: correction required.** Its arrows currently show *Map hazards → Set controls → Monitor → Verify → Correct*. For a detected critical-limit deviation, operational teaching should show *monitor → corrective action including affected-product disposition → verify effectiveness*. Codex treats corrective action and verification as distinct principles. The original PNG is preserved but **its arrow sequence must not be treated as authoritative** [A03].

**Diagram 02, organic/mechanisation: bounded review only.** It usefully separates organic certification from actual mechanisation outcomes. It cannot prove microbiological safety, machinery profitability, or scheme eligibility. Full regulatory and independent visual verification remain outstanding.

**Diagram 03, drinking-water treatment: correction required.** Its arrows could imply all source water must pass through serial microbial and fluoride treatments. Treatment must instead be selected from measured hazards; combine barriers only where both hazard classes require them. Chlorination is not fluoride-ion removal [A06][A07][A09]. Original PNG retained pending a properly reviewed replacement.

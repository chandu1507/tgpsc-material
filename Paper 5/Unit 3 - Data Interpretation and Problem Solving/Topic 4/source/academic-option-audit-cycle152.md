### Q21 — Horizontal cumulative-distance segment; key B retained
- **A (incorrect):** A constant high positive speed would make cumulative distance rise linearly, not stay horizontal.
- **B (correct):** A horizontal segment means cumulative distance remains constant over positive elapsed time; speed is zero throughout that segment.
- **C (incorrect):** Cumulative *distance travelled* cannot decrease; a negative slope can occur in a signed displacement graph, which is a different quantity.
- **D (incorrect):** A sustained nonzero acceleration changing speed would not yield a horizontal cumulative-distance segment.
**Condition:** The vertical axis must be cumulative path distance and the horizontal axis elapsed time, not position or signed displacement. Source [C152-S1].

### Q22 — Nine-month simple interest; key B retained
- **A (incorrect, ₹400):** At 8% yearly this is the interest for six months, not nine.
- **B (correct, ₹600):** 10,000 × 0.08 × (9/12) = 600.
- **C (incorrect, ₹800):** This is the interest for a full year.
- **D (incorrect, ₹900):** This would correspond to 13.5 months at the stated annual rate.
**Condition:** No capitalisation, fees or partial repayments; months/12 is the assumed year fraction. Source [C152-S2].

### Q23 — Solve annual simple-interest rate; key B retained
- **A (incorrect, 4%):** 20,000 × .04 × 3 = ₹2,400, not ₹3,000.
- **B (correct, 5%):** 3,000/(20,000 × 3) = .05.
- **C (incorrect, 6%):** Produces ₹3,600.
- **D (incorrect, 7%):** Produces ₹4,200.
**Condition:** The ₹3,000 is interest alone, not total amount; annual simple rate is sought. Source [C152-S2].

### Q24 — Recover duration from simple-interest amount; key C retained
- **A (incorrect, 2 years):** Would give ₹1,200 interest and ₹13,200 amount.
- **B (incorrect, 2.5 years):** Would give ₹1,500 interest and ₹13,500 amount.
- **C (correct, 3 years):** (13,800 − 12,000)/(12,000 × .05) = 3.
- **D (incorrect, 4 years):** Would give ₹2,400 interest and ₹14,400 amount.
**Condition:** Original principal remains ₹12,000 and the annual 5% rate is simple. Source [C152-S2].

### Q25 — General simple-interest amount formula; key C retained
- **A (incorrect in general):** P(1+R/100)^T is an annual compounding model; it may coincide at special values such as T=1 but is not the general simple-interest formula.
- **B (incorrect):** P+RT omits multiplication by principal and percentage scaling; its terms are dimensionally inconsistent if R is a percentage number.
- **C (correct):** P(1+RT/100) = P + PRT/100 with annual R% and T years.
- **D (incorrect):** PRT lacks the original principal in the amount and percentage scaling.
**Condition:** R is a percentage number, not decimal r; the two conventions must not be mixed. Source [C152-S2].

### Q26 — Definition of simple interest; key B retained
- **A (incorrect):** Compound interest capitalises accrued interest for later calculations, unlike the stipulated original-principal method.
- **B (correct):** Simple interest uses the original principal as its interest base.
- **C (incorrect):** A guaranteed yield is a separate contractual or risk claim, not the definition of the computation method.
- **D (incorrect):** A discount factor converts values across time; it does not name this interest calculation.
**Quality warning:** C and D are remote distractors; consider controlled strengthening in a future revision. Source [C152-S2].

### Q27 — Set overlap and quantified reasoning; key B retained
- **A (incorrect):** The fact that all supervisors are trained and some trained people volunteer does not force an overlap between supervisors and volunteers.
- **B (correct):** Not necessarily: construct trained persons S1 (supervisor, not volunteer) and V1 (volunteer, not supervisor); both premises hold.
- **C (incorrect):** Training duration is not a premise and does not establish a logical intersection.
- **D (incorrect):** Volunteer payment status is irrelevant to the stated set relationships.
**Quality warning:** C and D are implausible distractors; strengthen without changing the truth conditions. Source [C152-S3].

### Q28 — Affirming the consequent; key C retained
- **A (incorrect):** From P→Q and Q, inferring P is the invalid converse/affirming-the-consequent inference.
- **B (incorrect):** P is not necessarily false either; it can be true.
- **C (correct):** P may be true or false when Q is observed; both possibilities satisfy the premises.
- **D (incorrect):** Q is explicitly observed true, so this contradicts a premise.
**Proof:** Truth-table rows (P=true,Q=true) and (P=false,Q=true) both make P→Q true. Source [C152-S3].

### Q29 — Counts versus exposure-normalised complaint rates; key B retained
- **A (incorrect):** 150/20,000 = 0.75% mistakenly retains the earlier user denominator.
- **B (correct):** Before 200/20,000=1%; after 150/10,000=1.5%; the complaint count falls while the rate rises.
- **C (incorrect):** The rate does not stay at 1% under the supplied denominators.
- **D (incorrect for the constructed exercise):** Both counts and denominators are supplied, so the arithmetic rate is calculable.
**Condition:** The denominator must represent comparable service users in each period, with consistent complaint definitions. Actual dashboard interpretation requires this comparability check. Source [C152-S4].

### Q30 — Policy timing and causal inference; key C retained
- **A (incorrect):** A before–after fall does not establish that the policy certainly caused it.
- **B (incorrect):** Temporal order alone does not identify a mechanism or eliminate confounding.
- **C (correct):** Investigate alternative causes, selection, reporting changes and denominator shifts before making a causal claim.
- **D (incorrect):** Waiting time can be measured, though measurement methods and missingness require audit.
**Quality warning:** D is a weak distractor. The stem asks for the *strongest* conclusion, not a proof of policy ineffectiveness. Source [C152-S4].
